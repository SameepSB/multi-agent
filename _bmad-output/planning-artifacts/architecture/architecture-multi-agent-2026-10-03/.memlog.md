- (decision by user) Keep the documented three-agent collaboration model: coordinator owns orchestration and final synthesis; Weather and Travel Advisor own their domains, with parallel first-round work and coordinator-directed conflict follow-up. This binds module ownership and prevents competing recommendation pipelines.
- (decision by user) Use the existing Python and OpenAI API direction; target Python 3.12.x with dependency versions pinned in uv.lock and immutable container images. Do not silently switch model providers; Azure OpenAI remains a future option.
- (decision by user) Support laptop-first development and Azure cloud deployment using Docker Compose locally and Azure Container Apps for MVP production. Prefer Consumption scaling for cost; scale-to-zero is acceptable initially with documented cold-start trade-off, and revise minimum replicas when an SLO requires it.
- (decision by user) Retain an interactive CLI for local use and add a versioned authenticated REST API as the cloud entrypoint; both invoke the same coordinator application service.
- (decision by user) Secure MVP without asserting compliance: use managed identity and Key Vault for cloud secrets, local ignored environment files, authenticated ingress, internal-only worker services, and no cardholder data. Preserve future PCI DSS readiness through hosted/tokenized payment capture, isolated payment scope, and prohibition on PAN/CVV in prompts, data stores, telemetry, or logs; future scope requires formal assessment.
- (decision) Treat A2A as the coordinator-to-agent protocol and MCP as the Weather Agent-to-tool protocol; validate protocol payloads at boundaries, expose only explicitly approved tools, and keep the coordinator away from MCP.
- (decision) MVP has no shared mutable database: agent workloads are stateless and travel reference data is versioned with the application. Add persistence only when user history, tenancy, or durable workflow requirements are agreed.
- (decision) Use health/readiness checks, correlation and task identifiers, bounded timeouts and retries, redacted structured telemetry, automated tests, IaC, and immutable image promotion as cross-environment operating contracts.
- (question) Exact user authentication journey, production SLO/scale, and applicable PCI DSS scope are not specified; choose concrete settings during implementation and before production/payment processing.
